# CampusVote — порядок запуска на Windows

## 1. Подготовка

Это итоговый проект по дисциплине «Технологии распределённого реестра». В нём реализованы контракт для голосования «За / Против», автоматические тесты и русскоязычный веб-интерфейс на базе Scaffold-ETH-2.

Для первого запуска нужны Git, Node.js версии 22.13 или новее и доступ к интернету. Проверить версии можно командами `git --version` и `node -v`.

## 2. Создание рабочего проекта

1. Извлеките архив целиком через «Извлечь всё».
2. В распакованной папке запустите `setup.cmd`.
3. Дождитесь загрузки официального шаблона Scaffold-ETH-2 и установки зависимостей.
4. Откройте созданный каталог `campus-vote` в Visual Studio Code.

Если зависимости не установились, откройте терминал в `campus-vote` и выполните `corepack.cmd yarn install`.

## 3. Локальный запуск

Откройте три независимых терминала в корневом каталоге `campus-vote`:

1. Терминал 1: `corepack.cmd yarn chain` — локальная сеть Hardhat (окно не закрывать).
2. Терминал 2: `corepack.cmd yarn deploy` — развёртывание контракта CampusVote.
3. Терминал 3: `corepack.cmd yarn start` — веб-сервер.

Откройте в браузере http://localhost:3000. Маршруты: `/` — главная, `/vote` — голосование, `/results` — результаты.

## 4. Тесты

В новом терминале, также в корневой папке проекта, выполните `corepack.cmd yarn test`.

В проекте находятся 8 тестов: запись голоса, проверка события VoteCast, запрет повторного голосования и дополнительные сценарии. **Не указывайте успешные результаты до фактического запуска и проверки.** Сохраните снимок экрана с результатом.

## 5. MetaMask для демонстрации

Добавьте локальную сеть:

- Название: `Hardhat Local`
- RPC-адрес: `http://127.0.0.1:8545`
- Chain ID: `31337`
- Символ: `ETH`

На странице `/vote` подключите MetaMask. Используйте только локальную тестовую сеть. **Никому не передавайте пароль, секретную фразу восстановления и приватные ключи.**

Если тестовому адресу MetaMask нужен ETH для оплаты газа, можно перечислить на него 1 тестовый ETH из локального аккаунта Hardhat. Укажите **только публичный адрес** в терминале:

```powershell
$env:FUND_ADDRESS = "0xВАШ_ПУБЛИЧНЫЙ_АДРЕС"
corepack.cmd yarn workspace @se-2/hardhat hardhat run scripts/fund-local.ts --network localhost
```

Замените пример на действительный адрес длиной 42 символа. Реальные деньги не используются.

## 6. Ручная проверка

1. Откройте `/results` и зафиксируйте исходный результат.
2. Подключите MetaMask на `/vote` и выберите «За» или «Против».
3. Подпишите транзакцию и дождитесь сообщения об успехе.
4. Обновите `/results` и убедитесь, что счётчик увеличился.
5. Попробуйте проголосовать повторно с того же адреса: интерфейс должен запретить новое голосование.
6. Сделайте не менее трёх настоящих снимков экрана с короткими пояснениями «действие → результат».

При перезапуске `yarn chain` локальная сеть может сбросить данные; в этом случае выполните `yarn deploy` повторно.

## 7. Подготовка к сдаче

- Создайте **новый** публичный репозиторий GitHub для CampusVote, а не используйте репозиторий прошлой лабораторной работы.
- Загружайте исходные файлы, но не папку `node_modules`, приватные ключи, `.env` и сгенерированные временные файлы.
- Подготовьте **один PDF** по требованиям в `docs/REPORT_PLAN_RU.md`, со скриншотами реальной работы и ссылкой на GitHub.
- Срок сдачи из ELearn: **19 декабря 2026 года, 00:00**; безопаснее загрузить отчёт до 18 декабря.

Сначала убедитесь, что завершились `setup.cmd`, `yarn test` и запуск сайта. Затем оформляйте PDF.
