## 1. Введение

В ходе проекта разработано децентрализованное приложение CampusVote. Оно предназначено для голосования студентов по вопросу создания новой зоны отдыха. Голоса сохраняются в смарт-контракте на блокчейне.

## 2. Постановка задачи и обоснование выбора решения

Необходимо обеспечить прозрачный подсчёт голосов «За» и «Против», при этом один адрес должен голосовать только один раз. Выбран смарт-контракт Solidity, который хранит итоги и проверяет адрес отправителя.

## 3. Проектирование и реализация DApp-приложения

Смарт-контракт `CampusVote.sol` содержит функцию записи `castVote(bool)` и функции чтения `getTotals()` и `didVote(address)`. Событие `VoteCast` фиксирует факт голосования. Проверка `require(!voted[msg.sender])` запрещает повторный голос.

Веб-интерфейс реализован с использованием Scaffold-ETH-2, Next.js и RainbowKit. Страница голосования вызывает запись в блокчейн, а страница результатов показывает текущие значения.

## 4. Тестирование смарт-контракта и интерфейса

Проверки для подтверждения:
- Отправка одного голоса и изменение итогов.
- Событие `VoteCast` с адресом и выбранным вариантом.
- Повторное голосование с того же адреса отклоняется с сообщением `Повторное голосование запрещено`.
- Подключение MetaMask, подписание и отображение статуса транзакции.
