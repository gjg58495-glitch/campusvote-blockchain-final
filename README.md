# CampusVote — Финальный проект по технологии блокчейн

**Тема:** прозрачное голосование «За / Против» без возможности повторного голосования.

CampusVote — небольшое децентрализованное приложение на базе **Scaffold-ETH-2** (Hardhat + Solidity + Next.js + RainbowKit + Wagmi). Вопрос голосования: «Создать новую зону отдыха для студентов университета?».

## Возможности

- Контракт `CampusVote.sol`: один голос для каждого адреса.
- `castVote(bool)` — запись голоса; `getTotals()` и `didVote(address)` — чтение данных.
- `VoteCast` — событие при успешной отправке голоса.
- Проверка `require`: повторное голосование запрещено.
- Страницы: `/` — главная, `/vote` — голосование через кошелёк, `/results` — результаты.
- Подтверждение транзакций и сообщения об ожидании, успехе и ошибке.
- Unit-тесты для записи, события, `require` и дополнительных сценариев.

## Локальный запуск

Откройте терминал в корне проекта (где находится `package.json`).

1. Установите зависимости: `corepack.cmd yarn install` (Windows PowerShell).
2. Терминал 1: `corepack.cmd yarn chain`.
3. Терминал 2: `corepack.cmd yarn deploy`.
4. Терминал 3: `corepack.cmd yarn start`.
5. Откройте `http://localhost:3000`.
6. Unit-тесты: `corepack.cmd yarn test`.

Примечание: каждый терминал должен быть открыт **в корне проекта**. Терминал с `yarn chain` должен оставаться запущенным.

## MetaMask

Для тестирования с MetaMask добавьте локальную сеть:
- Network name: `Hardhat Local`
- RPC URL: `http://127.0.0.1:8545`
- Chain ID: `31337`
- Currency: `ETH`

Это тестовый блокчейн. Реальные ETH и приватные ключи использовать не нужно. Чтобы отправить тестовый ETH на адрес своего MetaMask, выполните в корне проекта (сначала укажите свой публичный адрес):

```powershell
$env:FUND_ADDRESS = "0xYOUR_PUBLIC_WALLET_ADDRESS"
corepack.cmd yarn workspace @se-2/hardhat hardhat run scripts/fund-local.ts --network localhost
```

На странице `/vote` подключите именно MetaMask через RainbowKit, подтвердите тестовый голос и посмотрите результат на странице `/results`.

## Документы для преподавателя

Перед сдачей сделайте не менее 3 скриншотов реальной работы и добавьте их в **один PDF-отчёт**. Требования к структуре, оформлению и содержанию — в `docs/REPORT_PLAN_RU.md`.

Репозиторий GitHub создаётся отдельно после успешного тестирования. Не загружайте `node_modules`, `.env`, ключи и артефакты сборки.

## Технологии и происхождение основы

Исходная структура создаётся из официального шаблона [Scaffold-ETH 2](https://github.com/scaffold-eth/scaffold-eth-2), распространяемого под лицензией MIT. Смарт-контракт, тесты, страницы и стили CampusVote являются самостоятельными файлами проекта.

## Язык проекта

Основные страницы, сообщения для пользователя, сообщения тестов, файлы документации и форма отчёта представлены на русском языке. Системные имена библиотек и идентификаторы функций остаются на английском по техническим причинам.
